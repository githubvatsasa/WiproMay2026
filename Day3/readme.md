#CSS:-
  - used to desing the page
  - types of css
      - Inline
      - Internal
      - External

- Inline CSS:-
    - in the line of you code itself 
    - using Style
    - High priority
    - used only whem 1 tag needs to be styled
- Internal css:-
    - CSS in the HTML file itseld
    - using Style tag
    - Medium priority
    - used when multiple tags need to be styled in one page
- External css:-
    - create a file with CSS extention
    - add it in the HTML with tab <link rel="stylesheet" href="style.css">
    - low priority
    - used when multiple pages needs to be styled
